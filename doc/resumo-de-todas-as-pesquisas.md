XAMPP:ele junta alguns programas dentro dele que serve para rodar um sistema, sem ter que jogar ele para internet e rodando so na tua maquina.

CRUD: o CRUD as propria palavra são as inicias de Create, Read, Update, Delete. No Create, os dados são inseridos; no Read, são consultados; no Update, são modificados; e no Delete, são excluídos. Todas essas etapas utilizam SQL para interagir com o banco.

SCRUM: o SCRUM e usada para gerenciar e desenvolver  projetos, ele e usado para organizar trabalhos tendo mais eficiencia e qualidade

PDO: ele utiliza o PHP para conectar com o banco de dados, ele serve para fazer consultas, inserir, alterar e excluir informações

APIS: ele serve como uma ponte entre 2 sistemas que usa protocolos de comunicações que são:
REST: regras para organizar a API usando URLs e métodos HTTP.
Endpoint: o endereço de cada recurso (/api/trens).
JSON: o formato em que os dados viajam, texto simples e fácil de ler.
Autenticação: provar quem você é. 
Autorização: definir o que você pode fazer.

SMT:é uma variável do PHP que guarda uma consulta preparada para o banco de dados. O nome vem de statement . Não é uma função do PHP, é só o nome que o programador escolheu.
