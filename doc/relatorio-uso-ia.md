# Relatório de Utilização da Inteligência Artificial

|---|---|
| **Ferramenta utilizada** | CLAUDE |
| **Objetivo** | Utilizamos a Inteligência Artificial para auxiliar no desenvolvimento do projeto Ferrorama, esclarecer dúvidas, gerar códigos e sugerir melhorias. |
| **Prompts** | Utilizamos prompts para aprender como resolver problemas e elaborar códigos mais densos que não tinhamos tanto conhecimento, nos aprofundamos em perguntas feitas à IA como por exemplo: "Como criar uma página PHP para cadastrar trens?", "Como conectar o PHP ao banco de dados MySQL?", "Como corrigir erros no código?" e "Como melhorar o visual das páginas do sistema?". E entre outros prompts para resolver erros e melhorar a codificação. |
| **Código produzido** | A IA auxiliou na criação e melhoria e funcionamento de códigos PHP, SQL, HTML, CSS e JavaScript, utilizados nas páginas de cadastro, edição, exclusão e gerenciamento de trens, sensores e rotas. |
| **Alterações da equipe** | A equipe revisou os códigos gerados, realizou adaptações e mudanças conforme os requisitos do projeto vinham chegando, ajustamos o layout das páginas e modificou as consultas SQL para atender às necessidades do sistema. |
| **Testes** | Foram realizados testes de cadastro, edição, exclusão e consulta de dados, verificando a comunicação entre o sistema PHP e o banco de dados MySQL. |
| **Problemas** | Durante o desenvolvimento, foram encontrados erros de conexão com o banco de dados,bugs, problemas em consultas SQL, incompatibilidade de colunas e dificuldades de organização do layout e principalmente erro de códigos em trocas de páginas e conexão. |
| **Correções** | Os erros foram analisados com o auxílio da IA, que sugeriu correções nos códigos PHP, ajustes nas consultas SQL e melhorias na estrutura das páginas. |
| **Reflexão** | A utilização da IA contribuiu para facilitar o desenvolvimento do projeto, auxiliar na resolução de problemas e melhorar o aprendizado da equipe. Entretanto, foi necessário revisar, adaptar e testar as soluções fornecidas, pois nem todos os códigos gerados funcionavam corretamente de primeira. |
