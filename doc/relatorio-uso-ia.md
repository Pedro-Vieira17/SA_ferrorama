# Relatório do Projeto Ferrorama

| Tema | Informações |
|---|---|
| Objetivo | Desenvolver um sistema web para cadastro e consulta de trens, sensores e rotas. |
| Desenvolvimento | O projeto foi criado com PHP, HTML, CSS, JavaScript e MySQL. |
| Funcionalidades | Login por perfil, dashboard, cadastro de usuários, gerenciamento de trens, sensores e rotas e consulta de clima. |
| Organização | Os arquivos PHP foram separados por responsabilidade e os estilos comuns foram centralizados no CSS do projeto. |
| Alterações da equipe | A equipe revisou o código, ajustou o layout e realizou alterações conforme os requisitos da Situação de Aprendizagem. |
| Testes | Foram feitos testes de cadastro, edição, exclusão e consulta de dados no banco MySQL. |
| Problemas encontrados | Erros de conexão, validação de formulários, consultas SQL e incompatibilidades entre campos. |
| Correções | Os problemas foram corrigidos por meio de revisão do código, testes das páginas e ajuste das consultas ao banco. |
| Resultado | O sistema permite o gerenciamento das informações ferroviárias e a consulta dos dados cadastrados. |
